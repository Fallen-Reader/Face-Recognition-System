# Face Recognition System

A team-based Face Recognition System built to detect, identify, and verify faces from images or live camera input. This project uses computer vision and machine learning techniques to recognize known faces efficiently and accurately.

## Features

- Face detection from images and webcam feed.
- Face recognition for known users.
- User registration / dataset creation.
- Real-time identification.
- Simple and modular project structure.
- Easy integration with future authentication systems.

## Tech Stack

- Python
- OpenCV
- NumPy
- face_recognition
- Tkinter / Flask / Streamlit *(if used, update accordingly)*
- SQLite / CSV *(if used, update accordingly)*

## Project Workflow

1. Collect face images for each user.
2. Train the system or encode known faces.
3. Detect faces from input image or webcam.
4. Compare detected faces with stored encodings.
5. Display the matched identity or mark as unknown.
